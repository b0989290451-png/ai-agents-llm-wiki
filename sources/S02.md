# S02｜Anthropic — Building Effective Agents
- 原始資料：https://www.anthropic.com/research/building-effective-agents
- 發布者：Anthropic
- 主題：Workflow 與 Agent、常見架構、評估與優化
- 檢索標籤：workflow, agent, routing, parallelization, evaluator

## Ingest 摘要（轉述）
這篇文章把 agentic systems 分成兩類：在預先定義的程式路徑上協調 LLM 與工具的是 workflow；由 LLM 動態決定自身流程及工具使用的是 agent。
常見 workflow 模式包含提示鏈、路由、平行化、協調者與工作者，以及評估者與優化者。反覆修正適合有明確可測的評估準則的工作。
文章建議先從簡單、可組合的方法開始，確定需求後才逐步增加架構複雜度；Agent 的操作也應保持透明。

## 邊界
不是每個具備工具的聊天機器人都能自動被歸類為自主 Agent；需要看實際控制流程。
