# S03｜OpenAI Developers — Building Agents
- 原始資料：https://developers.openai.com/tracks/building-agents
- 發布者：OpenAI Developers
- 主題：工具呼叫、執行流程、Agent 開發
- 檢索標籤：function calling, tool use, agent loop

## Ingest 摘要（轉述）
開發 Agent 的重點包括讓模型在任務需要時使用適當工具，而不是僅生成回答。Function calling 讓模型提出結構化的工具呼叫，由應用程式執行工具後把結果傳回模型，協助下一輪決策。
若只是一個回答問題的聊天介面，通常不足以構成具備行動能力的 Agent；需觀察是否能在任務流程中調用工具並依結果繼續處理。

## 可用證據卡
- S03-E1：Agent 可透過工具呼叫與外部資源互動。對應：工具使用。
- S03-E2：工具執行後的結果要回到模型，才能推進下一步。對應：Agent Loop。

## 邊界
模型生成工具呼叫並不等同於工具已成功執行；應用程式需處理結果及失敗情況。
