# AI Agents LLM Wiki & Teaching Slides

NCCU 生成式 AI 課程第十週作業：先討論、後生成，建立可查詢 Wiki；再從 Wiki 資料製作教學 HTML 簡報，並交付 Graph、檢查紀錄與反思。

## Wiki
- [Wiki 首頁](wiki/index.md)｜[S01–S05 摘要](sources/)
- 已準備五篇官方來源的**轉述摘要及證據卡**；不是將完整網頁原文下載存檔。
