# S04｜Microsoft Learn — Agent Architecture Components

- 主題：Agent 系統的架構組件
- 檢索標籤：architecture, components, input, resources

## Ingest 摘要（轉述）
Agent 系統通常由多個互相配合的部分構成：接收使用者輸入、解讀請求、取用外部資源及回傳結果。架構設計必須考慮這些服務與介面之間如何連結。
在教學簡報中可把它簡化為「輸入 → 模型決策 → 工具/資料 → 結果 → 回應」，但這是方便初學者理解的示意，不代表所有產品採用完全相同的架構。

## 可用證據卡
