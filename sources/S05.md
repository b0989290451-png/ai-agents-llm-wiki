# S05｜Microsoft Learn — Agent Framework Overview
- 原始資料：https://learn.microsoft.com/en-us/agent-framework/overview
- 發布者：Microsoft Learn
- 主題：Agent 與 Workflow 的選擇、多步驟協作
- 檢索標籤：workflow, agent framework, orchestration

## Ingest 摘要（轉述）
Microsoft Agent Framework 介紹了 Agent 與 Workflow 的互補角色：當工作需要彈性判斷與工具使用時可考慮 Agent；當步驟、資料流與控制點要明確規劃時可採用 Workflow。
有些任務可把多個步驟組成工作流程，並在適當節點安排檢查或人為核准；實作時仍需根據需求選擇，而非預設愈多代理越好。
